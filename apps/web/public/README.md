# public/ — static assets

ไฟล์ในโฟลเดอร์นี้ถูก serve ที่ root path `/` โดย Next.js
(เช่น `public/hero.mp4` → เข้าถึงได้ที่ `/hero.mp4`)

## Assets ที่หน้า Prisma ใช้
- `hero.mp4` — วิดีโอพื้นหลัง Hero (MP4/H.264, 1080p, ลูปเนียน, เงียบก็ได้เพราะเว็บ mute อยู่แล้ว)
- `hero-poster.jpg` — ภาพนิ่งกันจอดำระหว่างวิดีโอโหลด (ออปชัน)

วางไฟล์ตามชื่อด้านบนแล้วหน้า `/` จะดึงไปใช้อัตโนมัติ
